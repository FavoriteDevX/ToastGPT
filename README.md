The world's first **LLM (Large Loaf Model)** terminal assistant. Optimized for maximum crispiness, zero crumbs, and highly baked responses to your coding failures.

## 🚀 How to Run (via Codespaces)

1. Open this repository in a **GitHub Codespace**.
2. Run `npm install` to download dependencies.
3. Set your API Key in the terminal:
   ```bash
   export OPENAI_API_KEY="your-api-key-here"
   ```
4. Roast a command:
   ```bash
   node index.js "git push origin main --force"
   ```
